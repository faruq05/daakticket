# daakticket

The objective of this project is to create a functional and engaging blog post website using PHP where users can create, view, and interact with blog posts. The website will focus on user experience, performance, and ease of use.

Functionalites
1. User Authentication: Users will be able to register, log in, and log out to manage their posts and comments.
2. Post Creation and Management: Registered users can create, edit, and delete blog posts.
3. Commenting System: Users can leave comments on blog posts to encourage engagement and interaction.
4. Categories: Blog posts will be organized by categories to improve navigation and content discovery.
5. Search Functionality: Users can search blog posts by title, category, or keywords.
6. Responsive Design: The website will be mobile-friendly and responsive, adapting to different screen sizes.
7. Admin Panel: An admin panel will be provided to manage users, posts, and comments.
